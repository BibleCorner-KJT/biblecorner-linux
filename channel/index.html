📱 Android

Get the Android app

Bible Corner - KJT · free, from our website · works without internet
On Linux:
  1. Click Install in Software. Your browser downloads a small file.
  2. Open that file (click it in the browser's downloads). Software opens on Knowing Jesus Today.
  3. Click Install. From then on, Software keeps the app up to date by itself.
Needs Flatpak, which Fedora, Ubuntu, Linux Mint and most others already have. Or in a terminal:
flatpak install --user https://biblecorner-kjt.github.io/biblecorner-linux/knowing-jesus-today.flatpakref
